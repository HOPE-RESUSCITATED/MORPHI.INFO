## About

Morphi is a digital agency based in Louisiana, building immersive websites and bold visual identities for nonprofits and small businesses that make a difference.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS
- Three.js / React Three Fiber (particle system)
- GSAP (scroll animations)
- Lucide React (icons)

## Deployment

Auto-deploys to GitHub Pages via GitHub Actions on every push to `main`.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
